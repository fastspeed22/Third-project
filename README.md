Cyber Build is a Python-based cybersecurity program designed to help users understand and practice basic cybersecurity concepts through five different tools. The program includes a password strength checker that evaluates password security, a phishing detector that identifies suspicious words and phrases in messages, a file integrity checker that uses SHA-256 hashing to detect file changes, a log analyzer that searches system logs for errors, warnings, and possible brute-force activity, and an encryption tool that allows users to encrypt and decrypt files using password-based encryption. All five tools are organized through a simple menu-driven interface, allowing users to select a tool and return to the main menu when finished. I created Cyber Build to improve my Python programming skills while exploring practical applications of cybersecurity. I wanted to combine multiple security tools into one program and better understand how techniques like hashing, encryption, threat detection, and log analysis work. Through this project, I gained experience with Python functions, file handling, external libraries, conditional statements, and cybersecurity concepts. To run the program, download or clone this repository, open the project folder in a terminal, install any required dependencies, and run python main.py (or python3 main.py depending on your system). Once the program starts, use the menu to select one of the five cybersecurity tools and follow the instructions provided. Technologies: Python 3, SHA-256 Hashing, File Handling, Encryption Libraries, and Terminal/Command Prompt.
