# Third-project
Cyber Build is a Python-based cybersecurity program designed to help users understand and practice basic cybersecurity tools. It features five main functions: a password strength checker that evaluates password security, a phishing detector that identifies suspicious words and phrases in messages, a file integrity checker that uses SHA-256 hashing to detect file changes, a log analyzer that reviews system logs for errors, warnings, and possible brute-force activity, and an encryption tool that allows users to encrypt and decrypt files using password-based encryption. The program uses a simple menu-driven interface, allowing users to select different tools and return to the main menu when finished. Overall, Cyber Build combines several practical cybersecurity concepts into one program to demonstrate how Python can be used to identify potential threats, protect information, and improve digital security.
